# FPV Tracker Android — CURRENT

Нативное Android-приложение для ручного захвата произвольной цели, устойчивого сопровождения и повторного поиска после срыва. Основная тестовая платформа — Google Pixel 7a.

## Текущий код
- Kotlin / Android
- CameraX 1.6.2
- OpenCV Android 5.0.0.1
- minSdk 26
- targetSdk / compileSdk 37
- Java/Kotlin target 17

## Основной цикл
1. Оператор обводит цель рамкой.
2. Внутри bbox выбираются точки цели.
3. По фону вне цели оценивается движение камеры.
4. Это движение используется как начальный прогноз для LK optical flow цели.
5. Forward-backward проверка удаляет ненадёжные точки.
6. RANSAC affine оценивает положение, поворот и масштаб.
7. Многокадровая модель движения даёт устойчивый прогноз.
8. При падении качества включается SEARCH.
9. ORB + RANSAC ищут anchor/recent keyframe локально, затем глобально.
10. Подтверждённый объект заново инициализирует optical flow.

## Что не является основной архитектурой
- WebView;
- auto-bbox по одному тапу;
- NCC как главный tracker;
- гироскоп как обязательный источник;
- старые A/B/Replay экраны.

## Правило CURRENT
В рабочей ветке существует только один актуальный набор исходников и документации. Номерные копии и старые source zip не хранятся.
