# ESP Service Studio Universal

Статус: architecture/bootstrap

## Цель
Одна сервисная программа для:
- Mesh Messenger;
- ESP-контроллеров;
- готовых плат ESP + SX/LR;
- отдельных радиомодулей через ESP32-S3 Service Bridge;
- диагностики и восстановления.

## Главный принцип
Не смешивать «контроллер» и «радиочип».

Контроллер (ESP8285/ESP32/ESP32-S3/...) может получать основную прошивку.
Радиочип (SX1276/SX1262/SX1280/LR1121/LR2021/...) обслуживается отдельным адаптером и только разрешёнными для конкретного семейства операциями.

## UX
Обычный режим:
1. Подключение.
2. Автоопределение / профиль устройства.
3. Проверка совместимости.
4. Одна кнопка обновления пакетом.
5. Верификация после записи.

Ручные offsets, отдельные .bin и низкоуровневые операции уходят в «Восстановление / ручной режим».

## Mesh Messenger
Канонический будущий host-протокол: MM-UART/1.
EP2 LINK ASCII — временный compatibility/HIL path.
CRSF — только диагностика stock ELRS.

## Flutter
Flutter становится основной UI-оболочкой новой универсальной ветки.
Существующая Android/WebView v0.8 остаётся recovery path до parity.
